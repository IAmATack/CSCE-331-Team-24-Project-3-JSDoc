Class: DatabaseAccess

DatabaseAccess()

Database access layer. Responsibilities: - Execute parameterized SQL using a shared pool. - Provide generic CRUD helpers used by the logic layer. - Offer report utilities and transaction-aware insert helpers. - Keep logging minimal; focus on query execution and row counts.
